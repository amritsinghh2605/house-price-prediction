# 🏠 House Price Prediction Using Machine Learning

## 📌 Project Overview
This project predicts the approximate price of a house based on features such as location, area, number of bedrooms, bathrooms, and other property-related factors.

## 🎯 Objective
The main objective is to build a Machine Learning model that can estimate house prices using historical housing data.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook
- Streamlit

## 🔄 Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Selection
5. Model Training
6. Model Evaluation
7. House Price Prediction

## 🤖 Machine Learning
The project uses Machine Learning regression techniques to predict house prices.

## 📂 Project Structure
- `app/` – Application files
- `dataset/` – Dataset files
- `model/` – Trained model
- `notebook/` – Jupyter notebooks
- `website/` – Web interface
- `requirements.txt` – Required Python libraries

## 🚀 How to Run
1. Clone the repository.
2. Install the required libraries.
3. Run the application.
4. Enter the required house details.
5. Get the predicted house price.
